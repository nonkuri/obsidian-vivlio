# 第三章　岬の灯り

　灯台の扉には鍵がかかっていなかった。

　螺旋《らせん》階段を上るたび、鞄の中で封筒がかさりと鳴る。灯室には誰もいなかった。ただ、止まっているはずのレンズが、月のように淡く光っていた。

「手紙を持ってきたのね」

　声は階段の下から聞こえた。

　雨合羽を着た澄江が、息を切らして立っている。その手には、冬一郎から借りた写真と同じ銀色の星が刻まれた万年筆があった。

「凪さんを知っているんですか」

「姉よ。町を出たきり、戻らなかった」

　澄江は青い封筒を受け取ったが、開けようとはしなかった。これは姉が自分に宛てたものではない、と言った。

「姉は流星群の晩、ここで知らない人たちに手紙を書かせていたの。未来の自分へ、もう会えない誰かへ。星なら宛先を知っているって」

　透は窓の外を見た。雨脚は弱まり、雲の切れ間が一本の道のように海の上へ伸びていた。

「では、この手紙は誰のものなんでしょう」

　澄江は笑った。

「郵便は、受け取る人がいて初めて郵便になる。読んでみなさい」

　封を切ると、中には一枚の便箋が入っていた。

　——ここまで運んでくれたあなたへ。待つだけでは星に会えない夜もあります。そんなときは、自分で灯りをつけてください。

　短い文の下に、灯台の点灯手順が書かれていた。

　透と澄江は顔を見合わせた。ふたりで古い配電盤のレバーを押し上げると、レンズがゆっくりと回り始めた。白い光が雨を裂き、海を一周し、眠った町の屋根を照らした。

　その瞬間、雲がほどけた。

　最初の流星が、沖へ落ちた。
