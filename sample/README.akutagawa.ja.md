# Vivlio 0.8.0 サンプル — 芥川龍之介短編集

このパッケージは、同じ Markdown 原稿を Vivlio 0.8.0 で異なる判型・出力設定へ書き出したサンプルです。

## 内容

- `A5二段組.zip` — 入力原稿、表紙、`vivlio.yaml`、文庫版用 YAML
- `芥川龍之介短編集（A5二段組・トンボあり・塗り足し3mm）.pdf`
- `芥川龍之介短編集（A5二段組・トンボ等なし）.pdf`
- `芥川龍之介短編集（文庫版）.pdf`
- `芥川龍之介短編集.epub`

## 入力原稿を試す

1. `A5二段組.zip` を Obsidian Vault のルートへ展開します。
2. Vault に作られた `A5二段組` フォルダを右クリックします。
3. **Vivlio: 本としてプレビュー**を選びます。

`vivlio.yaml` の表紙や前付け・後付けのパスには `A5二段組/` が含まれています。フォルダ名やファイル名を変更する場合は、YAML 内の対応するパスも変更してください。

A5 二段組では `vivlio.yaml` を使います。トンボ付きの出力はトンボを有効にして塗り足しを `3mm`、トンボなしではトンボを無効にします。文庫版では、現在の `vivlio.yaml` を退避して `vivlio（文庫版）.yaml` の内容を `vivlio.yaml` として使用します。EPUB は A5 二段組の原稿と設定から書き出したリフロー型です。
