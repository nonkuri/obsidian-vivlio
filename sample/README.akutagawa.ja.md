# Vivlio 0.10.1 サンプル — 芥川龍之介短編集

このパッケージは、同じ Markdown 原稿を Vivlio 0.10.1 で異なる判型・出力設定へ書き出したサンプルです。

## 内容

- `A5二段組.zip` — 入力原稿、表紙、既定の `vivlio.yaml`、出力別の YAML
- `芥川龍之介短編集（A5二段組・トンボあり・塗り足しあり）.pdf`
- `芥川龍之介短編集（A5二段組・トンボ等なし）.pdf`
- `芥川龍之介短編集（四六判）.pdf`
- `芥川龍之介短編集（文庫版）.pdf`
- `芥川龍之介短編集.epub`

## 入力原稿を試す

1. `A5二段組.zip` を Obsidian Vault のルートへ展開します。
2. Vault に作られた `A5二段組` フォルダを右クリックします。
3. **Vivlio: 本としてプレビュー**を選びます。

`vivlio.yaml` の表紙や前付け・後付けのパスには `A5二段組/` が含まれています。フォルダ名やファイル名を変更する場合は、YAML 内の対応するパスも変更してください。

`vivlio.yaml` は、トンボなしの A5 二段組用です。ほかの出力には、名前が対応する次の設定ファイルを使います。

- `vivlio（A5二段組・トンボ等あり）.yaml` — トンボあり、塗り足し `3mm`
- `vivlio（四六判）.yaml` — 四六判、一段組
- `vivlio（文庫版）.yaml` — 文庫判、一段組

別名の YAML をファイルエクスプローラーで選択し、右クリックメニューの **Vivlio: この本を PDF に書き出す** または **Vivlio: この本を EPUB に書き出す** を選ぶと、その YAML の設定で出力できます。`vivlio.yaml` へ名前を変更する必要はありません。EPUB は既定の A5 二段組設定から書き出したリフロー型です。
