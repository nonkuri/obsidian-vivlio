# Vivlio 0.8.0 Sample — The Adventures of Sherlock Holmes

This package is a complete English-novel example produced with Vivlio 0.8.0. It demonstrates a vault-local custom stylesheet and includes both the source and the generated outputs.

## Contents

- `English Novel Sample.zip` — Markdown source, `vivlio.yaml`, and custom CSS
- `The Adventures of Sherlock Holmes.pdf`
- `The Adventures of Sherlock Holmes.epub`

## Open the source in Vivlio

1. Extract `English Novel Sample.zip` at the root of an Obsidian vault.
2. Right-click the resulting `English Novel Sample` folder.
3. Select **Vivlio: preview as a book**.

Keep the folder name when first extracting the sample. `vivlio.yaml` refers to paths beginning with `English Novel Sample/`, including the custom stylesheet. If you rename the folder or its files, update the corresponding YAML and CSS paths as well.

The active theme is `English Novel Sample/style/english-literary.css`. Its supporting stylesheets are in the same `style` directory.
