# 検証記録

## 構成と方針

2026-09-22。原稿7ファイル、図5点、表6点、MathML数式2件、脚注、文献、付録48行。
合成信号48系列×3欠測長×3ノイズ水準×3手法、1,296件の評価データは変更していない。
見出し・図表の番号の手入力やYAMLの追加CSSは使用しない。

要旨・文献・付録には、新しい標準プロパティ `vivlio-paper-role` で文書の役割だけを指定する。
番号は製品側で採番し、原稿の順序から毎回計算する。期待条件は `../index.md` のP01〜P07。

## 製品側の修正

- P01/P03：本文を一つの組版文書に結合し、章・節・図表を自動採番。目次とID参照も更新。
- P02：abstract/references/unnumberedは見出し番号なし、appendixはA・A.1形式。
- P04：ファイル境界の強制改ページを除去。数式と導入文、図とキャプションの分離を抑止。
- P05：短い表の分断を抑止。長表では表番号・表題・「続き」・列見出しを再掲。
- P06：和欧混植を左揃えにし、referencesの外部URLを脚注へ重複出力しない。
- P07：academic由来の図の固定最大幅・高さによる縮小と変形を解除。表は本文幅で配置。

## 実行した検証

`node test/run.mjs test/paper.check.ts` をWindows・Chrome・同梱Vivliostyleで実行。
Playwrightとjsdomがプロジェクト外の場合は `VIVLIO_PLAYWRIGHT` と `VIVLIO_JSDOM` に
パッケージの絶対パスを指定する。以下はすべて通過した。

- 原稿の並べ替え、同名ID・脚注リンクの衝突回避、前方・後方の図表参照、節番号参照。
- 分割した次の原稿が節から始まる場合も親の章番号を引き継ぐ。
- 章1〜4、付録A/A.1/A.2、要旨・参考文献の番号除外、目次の番号。
- continuous、roman-then-arabic、noneのページ番号設定。
- 5図の読み込み・縦横比・キャプション同居、図4と表3への原稿間参照。
- 長表S01〜S48が一度ずつ存在し、継続ページに表6と「続き」および列見出しを表示。
- 数式と導入文の同居、参考文献URLの単一掲載、末尾段落を含む左右のはみ出しなし。
- EPUBへの5PNG同梱、MathMLと付録末尾S48の収録。読書アプリ上の表示は未検証。

`npm test`、`npm run build`も通過した。変更箇所のlintでは、新規コードのエラーはないが、既存の `src/config/resolve.ts` の未変更行に4件の文字列変換エラーが残る。サンプルの追加CSS・手入力番号がないことも検査する。

## PDFの目視確認

`VIVLIO_PAPER_PDF=output/pdf/paper.pdf` を指定して組版検証を実行すると、
roman-then-arabic設定で検証用PDFを保存する。ページフロート導入後はA4・15ページ（導入前16ページ）。
ChromeのPDF出力を使い、プラグインと同じ印刷メディア、CSSページサイズ、余白0で出力した。
ObsidianのElectron画面からの書き出し操作自体は、この検証では実行していない。

PDFをPopplerで描画し、目次、数式、全図表、参考文献、付録、最終段落を確認した。
数式の導入文との分離、参考文献のURL重複・極端な字間、最終段落の欠落は解消。
表6は2ページに分かれ、2ページ目に「続き」が表示される。短い列定義表は1ページに収まる。

図を指定寸法のままページ上部へ浮動配置する。図3・図4が同じページに収まり、以前の図3ページの大きな余白を解消した。
図の表示順、キャプション同居、本文との重なりなし、参考文献より前への配置を自動検査する。
サンプルの図2・図3・図5は最初の参照から2ページ以内に配置されることも検査する。
ページ数は合格条件ではなく、フォント・ブラウザ・用紙設定によって変わり得る。

`sample/paper/paper.pdf` は利用者が実機出力した比較用PDFとして保持している。
今回の検証用PDFはリポジトリの `output/pdf/paper.pdf` にあり、実機出力とは別ファイル。
