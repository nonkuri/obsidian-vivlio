## 検証の観点

- 扉、目次、要旨から付録までの章順と目次のページ参照。
- 長い本文の自然な改ページ、ページ末の見出し、和欧混植、段落字下げ。
- 図1の設計図、図2の上下パネル、図3の誤差棒、図4の散布図、図5の3パネルが欠けずに表示される。
- 図の凡例・軸名・数値がA4の実寸で読め、縦横比が変わらず、キャプションが別ページへ孤立しない。
- 表3の9行6列、表5の列定義、表6の全48行。表6は複数ページにまたがり、見出し行が繰り返され、S01からS48まで一度ずつ載る。
- 方法の脚注が本文から参照でき、数式の添字・分数・総和・平方根が表示される。
- 考察から結果の図2・図4・表3への参照が正しい番号になる。目次とノート間の見出しリンクが移動できる。
- 既定では前付けをローマ数字、本文をアラビア数字にする。`continuous` と `none` でも確認できる。
- EPUBでは5点の図が同梱され、章順と内部リンクが保たれる。PDFと同じ改ページになることは期待しない。

## 標準paperの受け入れ条件

このサンプルは、実装の制約を原稿の手入力番号や追加CSSで補わない。見出し・図表の番号は出力側に任せ、図表への参照はIDで指定する。図の指定幅や表の48行も、収まるように縮小・削減して問題を隠さない。以下を受け入れ条件とし、実際の確認結果は `reproduce/verification.md` に記録する。

| ID | 期待する動作・合格条件 | 確認する対象 |
|---|---|---|
| P01 | 原稿をまたいで「はじめに」1、「方法」2、「結果」3、「考察と結論」4と自動採番し、節も2.1など親に追従する。原稿の並べ替えでも再採番する。 | 4章の見出し、目次、章への参照 |
| P02 | 要旨・Abstract・参考文献を通常の章番号に含めず、付録はA、A.1、A.2とする。除外や付録指定の方法がなければ製品側の未対応として扱う。 | 要旨、参考文献、付録 |
| P03 | 設計図から感度分析まで図1〜5、実験条件表から系列別結果まで表1〜6を通し番号にする。本文の相互参照とキャプションが一致する。 | fig-design〜fig-noise、tbl-design〜tbl-trials |
| P04 | 複数ファイルでも自然な本文の流れを保つ。導入文と数式、図表とキャプションを分離せず、不必要な大きな空白を作らない。 | 方法末尾、各原稿の境界、全図表 |
| P05 | 表6のS01〜S48を欠落・重複なく組み、継続ページの表番号と列見出しを示し、表の後の段落も紙面内に配置する。 | 付録の長表と末尾段落 |
| P07 | 指定した図の幅を尊重し、縦横比を保つ。表の列間隔とキャプションの位置を読みやすく揃える。 | 散布図、3パネル図、全表 |
| P06 | 参考文献と付録の和欧混植で字間を不自然に広げず、URLを文献内と脚注に重複掲載しない。 | 参考文献、再計算の説明 |

要旨・参考文献・付録には、ノートのフロントマターでそれぞれ `vivlio-paper-role: abstract`、`references`、`appendix` を指定する。本文の4章は既定の `body` のままにする。これは文書の役割の指定であり、番号の手入力やCSSによる回避ではない。番号なしの独立した原稿には `unnumbered` を使える。

paperは本文原稿を一つの組版文書に結合する。原稿の編集ファイルは分割したまま、章・節・図表を自動採番し、目次とID参照に反映する。付録のA、Bも出現順で決まる。章番号だけを参照したい場合は `<a href="02-methods.md#信号と観測値の生成" data-ref="sec"></a>` と書く。通常のノートリンクの表示名は維持される。

期待値を変更して合格にしない。修正内容・確認範囲は `reproduce/verification.md` に記録する。この一覧と検証記録は本文には含めない。

リリースZIPの `paper.pdf` は、2026-09-22に実機出力し全ページ確認した15ページのPDF。図3・図4は本文7ページ（PDFの9枚目）に同居し、長表と最終段落まで表示される。原稿変更後に自動更新されるものではないため、現在の原稿を検証するときは再出力する。フォント・環境により改ページ位置は変わり得る。

## 再計算

合成信号だけを使ったオリジナルの計算実験です。実測結果や既存論文を偽装していません。48系列×3欠測長×3ノイズ×3手法 = 1,296件を評価しています。

```sh
python -m pip install -r reproduce/requirements.txt
python reproduce/generate.py
```

Python 3.13と依存関係の指定版で再現できます。図の日本語フォントにはMeiryoまたはNoto Sans CJKを使います。生成器は図・CSV・集計表を更新しますが、解釈を含む本文は自動で書き換えません。実験条件を変更したときは本文の数値・説明も見直してください。
