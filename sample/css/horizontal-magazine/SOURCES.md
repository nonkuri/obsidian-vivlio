# 素材の来歴・ライセンス

作成日：2026-09-24。対象：Vivlio 0.17.3。

## 参照したサンプル

[Vivliostyle Web Magazine Sample](https://github.com/vivliostyle/vivliostyle_doc/tree/gh-pages/samples/webmag) の横書き印刷用を参考にしました。

なお、参考にしたのは、大見出し・リード・横書き段組み・裁ち落とし図版・柱とページ番号、A4／3mm塗り足しという組版の考え方です。記事、画像は独自に作成したものであり、参照先のCSS、HTML、文章、写真、ロゴ、スクリーンショットは、このパッケージに転載していません。CSSはVivlioの生成HTMLと設定変数に合わせて独自に記述しました。参照先と同じページマスターや、図版への本文回り込みを再現するものではありません。

## このパッケージの素材

| ファイル                                      | 来歴                                         |
| ----------------------------------------- | ------------------------------------------ |
| `horizontal-magazine.css`                 | 今回新規作成したCSS                                |
| `book/*.md`                               | 今回新規作成した架空の記事。実在の町・取材・発言ではない               |
| `book/images/*.svg`                       | 今回新規作成した図版。幾何学図形・文字をコードで記述。第三者の写真のトレースではない |
| `book/vivlio.yaml`                        | このサンプル用の設定                                 |
| `horizontal-magazine.pdf` / `preview.png` | 上記の原稿・CSS・SVGから生成した組見本                     |

文章・図版・CSSの作成にはAI（Codex）を使用しています。外部の素材集、ストック画像、実在ブランドのロゴ、フォントファイルは同梱していません。SVG内の文字は端末のフォントで描画します。PDFには出力環境のフォントがサブセット埋め込みされる場合があります。

ソースと派生組見本は、このリポジトリと同じAGPL-3.0-or-laterで提供します。ライセンス本文を `LICENSE` に同梱しています。ユーザーが別の素材やフォントに差し替える場合、その素材の権利・利用条件は別途確認してください。
