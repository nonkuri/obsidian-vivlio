作成日：2026-09-24。対象：Vivlio 0.17.3。

## 参照先

[Vivliostyle Web Magazine Sample](https://github.com/vivliostyle/vivliostyle_doc/tree/gh-pages/samples/webmag) と縦書き用の `viv-print-v.css` / `viv-style-v.css` を構成・技術の参考として確認しました。

なお、参考にしたのは、組版の考え方です。記事、画像は独自に作成したものであり、参照先のCSS・HTML・文章・写真・ロゴ・スクリーンショットは同梱していません。また、参照先と同じページマスターや、図版への本文回り込みを再現するものではありません。原稿は架空の町と作業室を題材に新規に書いたフィクションであり、実在の取材・人物の発言・報道ではありません。SVGは幾何学図形をコードで組み立てた新規のイラストで、第三者の写真やイラストのトレースではありません。

## ファイル別の来歴

| ファイル | 来歴 |
|---|---|
| `vertical-magazine.css` | Vivlio用に新規作成。既存の本リポジトリ内サンプルと共通の設定方式を使用 |
| `book/*.md` | 今回新規作成したオリジナルの架空記事2本 |
| `book/images/cover.svg` | オリジナルの表紙。屋根、水面、文字で構成 |
| `book/images/rain.svg` | オリジナルの架空の町の風景 |
| `book/images/repair.svg` | オリジナルの紙・糸巻き・定規の静物 |
| `book/images/detail.svg` | オリジナルの屋根・しずく・受け皿の模式図 |
| `book/vivlio.yaml` | 今回の組版用設定 |
| `vertical-magazine.pdf` / `preview.png` | 上記ソースから生成した組見本 |

CSS・文章・図版の作成にはAI（Codex）を使用しました。ストック画像、実在ブランドのロゴ、外部画像、フォントファイルは同梱していません。SVGの文字は端末のフォントで描画します。PDFには生成環境のフォントのサブセットが埋め込まれる場合があります。
