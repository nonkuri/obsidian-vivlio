# 句集・歌集のサンプル

同梱テーマ `haiku` と `tanka`、作品記法、原稿をセットで試すサンプルです。Vivlio 0.17.0以降で利用できます。テーマはプラグインに内蔵され、追加CSSは不要です。

- [句集「川までの道」](haiku/index.md)：俳句と自由律の作例8作品。
- [歌集「改札の向こう」](tanka/index.md)：短歌と二行書きの作例8作品。

文章・作品・作者名はこのサンプルのための創作です。外部の作品・画像・フォントファイルは収録していません。

## 使い方

1. `haiku` または `tanka` フォルダ全体をVaultへコピーします。
2. フォルダ、または中の `vivlio.yaml` から本としてプレビューします。
3. PDF / EPUBを書き出します。

四六判・縦一段組・アタマ揃えです。`versePerPage: 2` を `1` または `3` に変えるだけで、同じ原稿の掲載密度を比較できます。`columns` は段数であり、作品数ではありません。設定ウィザードにも句集・歌集のプリセットがあります。

YAMLは本文・見出しを明朝体のフォント候補に固定しています。フォントの実体は環境のものを使うため、環境によって字形や折り返しが変わります。テーマだけを選択しても判型・組方向・字数行数は変更されません。

本扉は書名・副題をやや右上、著者名をその左下に配置します。中央に密集させず、ページ端にも寄せすぎない間隔を取ります。この配置は小説・二段組小説・エッセイと共通の内蔵処理です。

## 原稿記法

一つのコールアウトが一句・一首です。作品同士は `>` のない空行で区切ります。通常の段落は序文・解説などの散文として扱います。

```markdown
# 春の川辺

> [!haiku]
> 春の川橋の向こうに母の傘

> [!haiku] 故郷にて
> 木蓮《もくれん》の影をまたいで帰りけり
>
> 作者：山田花子
```

`[!haiku]` / `[!tanka]` の後の任意の文字列は、短い前書き・詞書です。省略すると空欄になり、種類名は印刷されません。末尾の独立段落が `作者：` または `作者:` で始まる場合だけ作者欄として扱います。個人集では作者欄を省けます。複数作品を一つのコールアウトへまとめないでください。

本文として文字通り「作者：」から始まる最終段落を置く場合は、`<span>作者：</span>本文` と書くと作者欄にはなりません。詞書は一行のプレーンテキストを基本とします。

通常の改行はMarkdownの段落内の折り返しです。作品として改行したい位置には `<br>` またはMarkdownの強制改行（行末の半角スペース2つ）を入れます。空白が見える `<br>` をサンプルでは使っています。作品内の全角空白を散文用の字下げに置き換えることはありません。通常の半角空白はHTMLの規則で畳まれます。

```markdown
> [!tanka] 二行書きの作例
> 最終の電車を降りて見上げれば<br>星は名前を知らぬままある
```

五七五や五七五七七に合わせた自動改行・音数の補正は行いません。ルビ・傍点・縦中横は共通記法を使用できます。Obsidian側では通常のコールアウトとして見え、Vivlioの出力時に作品の体裁になります。「コールアウト」の記法変換設定を有効にしてください。

## 章・連作・ページの扱い

サンプルは一章一ノートで、`index.md` が順序を指定します。`#` を章、`##` を連作にします。各作品に見出しを付ける必要はありません。章名を本の `title` と同じにすると共通の書名見出し除去が働くので、別の章名にしてください。

- 章題は独立した半扉です。縦組みでは左ページから始まり、必要なら直前に白ページを補います。章題は版面の左右中央、上から本文4字分下げた位置に置き、柱・ノンブルを表示しません。半扉もページ数に含めます。
- 半扉の裏（次の右ページ）から作品を始めます。裏白を設ける中扉方式ではありません。
- 連作見出しは新しい作品ページの冒頭に置き、最初の作品と同じページに組みます。見出し用に3字分の幅を確保するため、このページの作品間隔だけ狭くなります。掲載数の上限は変わりません。
- 本文には上部小口側の柱（右：書名、左：章名）と下部小口側のノンブルを表示します。改丁で補う白ページには表示しません。

一つのノートに本全体を書く場合は、書名の `#` の下に `##` を章、`###` を連作として置きます。本文に残る最上位の見出しが章として扱われます。章扉の左右はテーマの既定値であり、開始ページの左右を明示指定する場合は組見本で確認してください。

この構成は出版物にある複数の形式から選んだテーマの方針です。「歌集・句集はすべてこの形式」という意味ではありません。[調査と設計根拠](../docs/haiku-tanka-theme-direction.md)も参照してください。

章末に一作品だけ残っても、配置枠を拡大せず残りを空けます。意図的に作品の組み合わせを変えたい場合は、コールアウトの間に `［＃改ページ］` を置きます。作品の中には改ページを入れないでください。

字数・明示改行・詞書・作者から行数を推定し、枠に収まりにくい作品は別のページ群へ分けて警告します。これは実測した収まりの保証ではありません。長い作品は必要なら複数頁へ流れ、文字を縮小・切り捨てません。フォントや字詰めを変更した場合もプレビューで確認してください。長文の詞書、自注中心の合同集、天地揃え、複雑な多行書きの字下げは初版の標準対象外です。

## EPUB

作品の順序・詞書・作者・明示改行・ルビを保持します。作品数／頁のグループと固定寸法は外し、読書アプリにページ分割を任せます。PDFと同じ紙面にはなりません。EPUBパッケージ内の構造とブラウザでのリフローは検証しますが、個々の読書アプリでの表示は別途確認してください。

## 開発時の検証と出力

```powershell
$env:VIVLIO_PLAYWRIGHT = 'C:/path/to/node_modules/playwright'
$env:VIVLIO_JSDOM = 'C:/path/to/node_modules/jsdom'
$env:VIVLIO_VERSE_OUTPUT = 'output/pdf/verse'
node test/run.mjs test/verse.check.ts
```

Playwright・jsdomが通常のモジュール解決で使える場合は最初の2変数は不要です。Chromeを使い、`VIVLIO_BROWSER` で別チャンネルを指定できます。

出力先には `haiku-1.pdf`〜`haiku-3.pdf`、`tanka-1.pdf`〜`tanka-3.pdf`、`haiku.epub`、`tanka.epub` とページ画像・レイアウト記録を作ります。1作品／頁は各16頁、2・3作品／頁は各14頁です（同梱サンプル、検証時のChrome・フォント環境）。収録数が少なく章境界もあるため、2作品と3作品で総頁数が同じでも本文の配置は異なります。

検証後に `node test/package-verse.mjs` を実行すると、同じ出力先へ `vivlio-sample-verse-<version>.zip` を作ります。ZIP内の `haiku/`・`tanka/` が原稿、`examples/` がPDF・EPUBです。検証コードはリポジトリにあります。配布用ZIPは sample/downloads/ に保存し、プラグインのリリース資産には添付しません。

作品数、作品の分断、作品・文字の紙面内への収まり、短い詞書・作者の同頁配置、改ページ、前後付け、長い作品の全量保持、EPUB構造を検証します。変換記法と設定の回帰テストは通常の `npm test` に含まれます。
