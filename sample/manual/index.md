# マニュアルサンプル：小さな資料を、一冊に

Vivlio 0.15.0以降で、このフォルダ全体をVaultにコピーし、`vivlio.yaml` を右クリックしてプレビューを開きます。追加CSSは不要です。図は同梱のSVGで、オンライン画像やフォントに依存しません。図は説明用の模式図であり、実際の画面キャプチャではありません。

## 原稿順

1. [[01-start|原稿を準備する]]
2. [[02-layout|紙面を整える]]
3. [[03-delivery|確認して配布する]]
4. [[04-checklist|配布前チェックリスト]]

このindexは本文に含めません。図表番号は標準manualテーマが本文の掲載順に自動生成します。章の構造と見出しは原稿どおりに保ちます。

## 記法

- 操作手順は通常の番号付きリスト。長い手順はページをまたげます。
- 注意・補足は `> [!warning] 注意：…`、`> [!tip] ヒント：…`、`> [!note] 補足：…`。タイトルに種類を明記すると、色に頼らず意味を伝えられます。
- キー名は `<kbd>Enter</kbd>`。
- 図は `<figure id="fig-name"><img src="figures/name.svg" alt="説明"><figcaption>説明</figcaption></figure>`。
- 表は `<table id="tbl-name"><caption>説明</caption>…</table>` または `figure` と `figcaption` で囲む形式。
- 本文内の図表参照は `<a href="#fig-name" data-ref="fig"></a>`。別原稿なら `<a href="01-start.md#fig-flow" data-ref="fig"></a>`。表は `data-ref="tbl"`。
- 字下げを使う本は `paragraphIndent: 1em`。既定は字下げなしです。

## 受け入れ条件

| ID | 確認内容 |
| --- | --- |
| M01 | 扉・目次・本文・奥付が揃い、本文が四つの原稿順に並ぶ。 |
| M02 | 図1・図2、表1・表2が通し採番され、別原稿への図参照も一致する。 |
| M03 | 図とキャプションが同じページに収まり、図が後続の章へ移動しない。 |
| M04 | 通常手順、入れ子リスト、キーボード表記、注意・ヒント・補足を区別できる。 |
| M05 | 長い設定名とコードがA5の紙面からはみ出さず、コードの末尾が残る。 |
| M06 | 長表のC01〜C36が欠落・重複なく表示され、列見出しが各ページで繰り返される。 |
| M07 | 長いコールアウトが分割でき、末尾の「確認記録を保存します。」まで残る。 |
| M08 | A5とA4の両方で本文・画像・表がページ内に収まり、EPUBにも図・番号・参照・末尾が残る。 |

検証方法と確認結果は、フォルダ外の `manual-README.md` を参照してください。
