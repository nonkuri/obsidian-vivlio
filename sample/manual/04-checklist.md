# 配布前チェックリスト

<a href="#tbl-checklist" data-ref="tbl"></a>を使い、確認した項目に記録を残します。長い表がページをまたいでも、列見出しを読みながら作業できます。

<figure class="tbl" id="tbl-checklist">
<figcaption>原稿・紙面・配布ファイルの確認項目</figcaption>

| ID | 対象 | 確認すること |
| :--- | :--- | :--- |
| C01 | 書名 | 資料の内容を表す名前になっている。 |
| C02 | 副題 | 対象者と用途が分かる。 |
| C03 | 著者 | 作成者の表示を確認した。 |
| C04 | 原稿順 | indexのリンクが読む順番に並んでいる。 |
| C05 | 見出し | 操作の目的が見出しだけで分かる。 |
| C06 | 階層 | 見出しの深さに不自然な飛びがない。 |
| C07 | 対象者 | 必要な知識を最初に説明した。 |
| C08 | 前提 | 操作を始める条件を明示した。 |
| C09 | 手順 | 主要な操作を一項目ずつに分けた。 |
| C10 | 結果 | 操作後に何が起きるかを示した。 |
| C11 | 分岐 | 条件による違いを操作より先に書いた。 |
| C12 | 注意 | 重要な注意を操作前に読める。 |
| C13 | 補足 | 本文と補足を見分けられる。 |
| C14 | キー | キー名と入力する文字を区別した。 |
| C15 | 用語 | 同じ機能に同じ名前を使っている。 |
| C16 | 図の位置 | 説明と図が近くに配置されている。 |
| C17 | 図の文字 | 完成時のサイズで読める。 |
| C18 | 代替文 | 画像の内容を説明する文がある。 |
| C19 | 図番号 | キャプションと参照の番号が一致する。 |
| C20 | 表番号 | 本文から目的の表へ移動できる。 |
| C21 | 列見出し | 各列の内容と単位が分かる。 |
| C22 | 表の続き | 次ページにも列見出しがある。 |
| C23 | 表の末尾 | 最終行が欠けずに表示される。 |
| C24 | コード | 折り返した行と原稿の改行を区別できる。 |
| C25 | 長い名前 | 設定名や保存先が紙面から出ていない。 |
| C26 | ページ番号 | 前付けと本文の番号が設定どおりである。 |
| C27 | 柱 | 書名や章名が本文に重なっていない。 |
| C28 | 目次 | 必要な章が掲載されている。 |
| C29 | 余白 | 不自然な空白の原因を確認した。 |
| C30 | 白黒 | 色を使わなくても注意の種類が分かる。 |
| C31 | PDF | 書き出したファイルを開き直した。 |
| C32 | EPUB | 使う閲覧ソフトで文字と図を確認した。 |
| C33 | 奥付 | 版や発行者の表示に誤りがない。 |
| C34 | 旧版 | 以前の配布物を別に保存した。 |
| C35 | 引き継ぎ | 原稿・設定・図をまとめた。 |
| C36 | 確認記録 | 確認日と修正内容を記録した。 |

</figure>

これで配布前の確認は完了です。次回は保存した原稿と設定から作業を再開できます。
