# 一般書・エッセイのサンプル

`essay` テーマ用の現代の日常を題材にしたユーモアエッセイ「やる気は充電中」です。スヌーズと通知をめぐる原稿2点、ポップな表紙、模式図1点、引用、箇条書き、番号付きリスト、脚注、ルビ、傍点、補足を含みます。追加CSSやHTMLのインラインスタイルは使わず、Markdown・YAMLの既存設定・画像だけで構成しています。原稿側でレイアウトを上書きせず、同梱のessayテーマの機能を利用します。

## 使い方

1. Vivlio 0.16.0以降を利用します。
2. [essay フォルダ](essay/)をそのままVault内へコピーします。
3. `vivlio.yaml` またはフォルダからプレビュー・PDF/EPUB書き出しを実行します。`index.md` が原稿順を指定します。

初期設定は四六判・縦一段組・40字×16行です。テーマだけを選択しても判型や組方向は変更されないため、設定ファイルも併せて使用してください。

サンプルYAMLは `fontFamily`（本文）、`headingFontFamily`（見出し）、`mboxFontFamily`（柱・ノンブル）をゴシック体のフォント候補に固定しています。これらを省略すると設定タブのフォントを引き継ぎます。`theme: essay` だけではウィザードのプリセットは適用されません。ページ上部の柱とノンブルは `mboxFontFamily` で別指定でき、未指定なら本文フォントに従います。以前のサンプルをVaultにコピー済みの場合は、原稿・YAML・imagesフォルダをまとめて更新してください。

章は新しいページから始まり、節見出しは本文に続きます。扉・目次・柱・ノンブル・奥付は `novel` の基本設計を引き継ぎます。図版は横組みのキャプションを添えて本文の流れに配置し、自動図番号は表示しません。EPUBはリフロー型のため、読書アプリによって改ページ・余白・図版の位置は変わります。

## calloutの使用例

本文には `note`（本日の発見）、`tip`（私調べの攻略法）、`warning`（翌朝の自分へ）、`quote`（本日の決議）を収録しています。細い囲み・角丸の破線枠・前後が二重線の囲み・前後の括り罫の表示は、同梱の `essay` テーマが担当します。この種類別表示を含むプラグインのビルドが必要です。サンプルには追加CSSはありません。

## 開発時の確認

```powershell
$env:VIVLIO_PLAYWRIGHT = 'C:/path/to/node_modules/playwright'
$env:VIVLIO_JSDOM = 'C:/path/to/node_modules/jsdom'
$env:VIVLIO_ESSAY_OUTPUT = 'output/essay'
node test/run.mjs test/essay.check.ts
```

Playwrightとjsdomが通常のモジュール解決で利用できる場合、最初の2変数は不要です。Chromeを使用し、`VIVLIO_BROWSER` で別のPlaywrightブラウザチャンネルを指定できます。

四六判と文庫判の組版、節見出しの継続、図版の読み込み、本文要素の紙面内への収まり、前後付け、EPUBへの画像収録を確認します。さらに1ノート構成の章見出しと長い引用の分割を確認します。出力先を指定した場合はサンプルPDF・EPUB・各ページ画像・レイアウト記録を保存します。EPUB読書アプリでの見え方は別途確認してください。

## 素材

図版を原稿からリサイズする場合は、`![起床会議の模式図。全会一致まで、あと一杯。|50mm](images/walk.svg)` のように説明文の末尾へ幅を追加できます。キャプションにサイズ指定が残らない修正版のプラグインを使用してください。単位と Obsidian・GFM との違いは[マニュアルの画像の項目](../manual/05-writing-and-structure.md#画像)を参照してください。

模式図SVGは表示寸法 `width="180" height="77"`（幅約47.6mm）を指定しています。`viewBox="0 0 420 180"` は内部の描画座標です。表示寸法よりviewBoxを優先していた旧ビルドでは、実機の画像参照情報を読み取ると図が大きくなります。YAMLの設定で補うのではなく、SVG寸法の読み取りを修正したプラグインを利用してください。検証ではObsidianの画像参照情報も与え、図本体の幅を測定しています。

文章・引用・模式図はこのサンプルのために作成したものです。表紙はOpenAIの画像生成ツールで制作しています。外部の写真やフォントファイルは同梱していません。リポジトリのライセンスに従って利用できます。

表紙の生成指示は [essay-cover-prompt.md](essay-cover-prompt.md) に保存しています。表紙PNGは1031×1526pxで、四六判では約206dpiです。印刷所への本番入稿では必要解像度に合わせた画像を用意してください。

表紙は `cover: ./images/cover.png` と明示し、本のフォルダ内の画像だけを参照します。この指定には本の相対パスを完全一致で優先する修正版が必要です。旧ビルドで試す場合は、Vault直下に `essay` を置き、`cover: essay/images/cover.png` とVaultルートからのパスを指定してください。
