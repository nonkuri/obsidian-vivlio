# Vivlio 0.14.0 論文・レポートサンプル

「連続欠測を含む周期時系列の補間法比較」を題材にした模擬論文です。
合成信号を使った組版検証用資料であり、実在の研究・被験者・測定施設の報告ではありません。

## 開き方

1. Vivlio 0.14.0以降をデスクトップ版Obsidianで有効にします。
2. このZIPの `paper` フォルダ全体をVaultへコピーします。
3. `paper/vivlio.yaml` を右クリックしてVivlioのプレビューを開きます。
4. プレビューのPDF・EPUBボタンから出力できます。

`index.md` が本文7ファイルの順番を指定します。図5点、表6点、数式・脚注、48行の付録表を含み、番号やページフロートは標準paperテーマに任せています。追加CSSは不要です。

## 同梱内容

- `paper/paper.pdf`: 2026-09-22にObsidianから実機出力し、全15ページを確認したPDF。フォント・環境により再出力時の改ページ位置は変わります。
- `paper/00-abstract.md`〜`06-appendix.md`: 入力原稿。
- `paper/figures/`: 生成済みのPNGとSVG。組版だけならPythonやネットワーク接続は不要です。
- `paper/data/`: 合成データ、集計結果、生成環境の記録。
- `paper/reproduce/`: 再生成用Pythonコード、依存関係、検証記録。
- `paper/index.md`: 使い方と受け入れ条件。
