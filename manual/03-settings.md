# Vivlio プラグインの設定

[前: まずは一冊作ってみる](02-first-book.md) / [マニュアル目次](00_vivlio_plugin_manual.md) / [次: 本ごとの設定](04-book-configuration.md)

Obsidian の **設定 → Vivlio** で、Vault 全体の既定値を変更できます。本ごとの `vivlio.yaml`、ノートごとの `vivlio-*` フロントマターがある場合は、そちらが優先されます。

## 設定の優先順位

```text
プラグイン設定 < vivlio.yaml < ノートの vivlio-* フロントマター
```

設定タブは「新しい本をどんな状態から始めるか」を決める場所です。本ごとに固定したい値は `vivlio.yaml` に書いてください。

## 全般

| 設定 | 初期値 | 解説 |
|---|---:|---|
| **既定のプリセット** | 文庫本（縦組み） | **本の設定を作成**ウィザードを開いたときの初期プリセット。文庫本、Web 小説の書籍化、カスタムから選びます。 |
| **UI 言語** | Obsidian | `Obsidian` はアプリの言語に追随。日本語または English に固定できます。 |

プリセットはウィザードの出発点であり、既存の `vivlio.yaml` を自動変更しません。

## 組版

| 設定 | 初期値 | 解説 |
|---|---:|---|
| **既定テーマ** | `novel` | 同梱テーマまたは Vault 内の `.css`。自作テーマも候補に出ます。 |
| **既定用紙サイズ** | `文庫` | `A4`、`A5`、`B5`、`JIS-B5`、`JIS-B6`、`A6`、`文庫`、`新書`、`letter`。 |
| **既定書字方向** | `vertical-rl` | `vertical-rl` は縦組み、`horizontal-tb` は横組み。 |
| **既定の脚注モード** | `gcpm` | 脚注の位置とマークアップを決めます。下記参照。 |
| **段落の字下げ** | 空欄 | 空欄はテーマ任せ。`0`、`1em` などを指定できます。単位なしの 0 以外の数値は em として扱われます。 |
| **字下げする段落** | `auto` | どの段落へ字下げを適用するか。下記参照。 |
| **行頭の全角スペースを削除する** | オン | 原稿の全角スペースを印刷用 CSS の字下げへ置き換えます。 |
| **追加 CSS** | 空欄 | Vault 相対の CSS パス。最終段に追加されるため、テーマや本の設定を上書きする全 Vault 共通の調整に向きます。 |

### 用紙サイズ

`文庫` と `A6` はともに `105mm 148mm`、`新書` は `103mm 182mm`、`JIS-B6` は `128mm 182mm` に解決されます。`vivlio.yaml` では `128mm 188mm` のような任意の CSS サイズも指定できます。

### 脚注モード

| 値 | 動作 | 向いている用途 |
|---|---|---|
| `gcpm` | 呼び出したページの地（ページ下部）へ配置 | 紙の本、PDF |
| `pandoc` | 章の末尾にまとめる | 章末注を使う本、互換性重視の EPUB |
| `dpub` | DPUB-ARIA の注として出力 | ポップアップ脚注に対応する EPUB リーダー |

脚注の見え方はテーマと出力先にも左右されます。配布する EPUB リーダーで実機確認してください。

### 字下げモード

| 値 | 動作 |
|---|---|
| `auto` | 原稿に行頭全角スペースがあればそれに従い、なければ始め括弧で判断 |
| `manuscript` | 原稿で行頭全角スペースがある段落だけ字下げ |
| `brackets` | `「` `『` `（` で始まる会話文以外を字下げ |
| `all` | 会話文を含むすべての段落を字下げ |

通常は **行頭の全角スペースを削除する**をオンのまま使います。オフにして CSS の字下げも残すと、環境によって二重に下がる可能性があります。

## フォント

| 設定 | 初期値 | 解説 |
|---|---|---|
| **本文フォント** | OS 横断の明朝体スタック | CSS の `font-family` と同じカンマ区切り。 |
| **見出しフォント** | OS 横断のゴシック体スタック | 見出し用。 |
| **等幅フォント** | `Consolas` など | コード用。 |
| **フォントフォルダ** | `fonts` | Vault 相対。将来の自動検出用設定です。0.1.3 では下記の制限があります。 |
| **指定フォントが無い場合に警告する** | オン | 書き出し前に先頭の指定フォントを確認し、代替書体を表示します。 |
| **EPUB にフォントを埋め込む** | オフ | フォントフォルダのフォントを EPUB に同梱します。PDF への埋め込みとは別です。 |

フォント欄には、利用できる場合は PC にインストール済みのファミリ名が候補として出ます。選択すると既存のフォールバック列を残して先頭へ追加されます。

> 日本語フォントを埋め込むと、EPUB のファイルサイズが大幅に増加します。また、フォントによっては再配布や埋め込みが禁止されています。ライセンスを確認してから有効にしてください。

本ごとにフォントファイルを明示するには `vivlio.yaml` の `embedFonts` を使います。対応形式は WOFF2、WOFF、OTF、TTF です。

> **0.1.3 の制限:** フォントフォルダの自動走査はまだ実装されていません。画面上の説明にかかわらず、`@font-face` が自動生成されるのは `vivlio.yaml` の `embedFonts` に明示したファイルだけです。EPUB の **フォントを埋め込む**も、この `embedFonts` で登録されたフォントを同梱するかどうかに作用します。

## 出力先

| 設定 | 初期値 | 解説 |
|---|---:|---|
| **出力フォルダ** | `_output` | `output` が指定されていない本の出力先。Vault 相対。 |
| **書き出し後にファイルを開く** | オン | OS の既定アプリで生成物を開きます。 |
| **.yaml / .css / .epub をファイルエクスプローラーに表示する** | オン | Vivlio がこれらの拡張子を引き受け、Obsidian 内で表示できるようにします。変更後は Obsidian の再起動が必要です。 |

本の `output` または書き出しダイアログのパスが、**出力フォルダ**より優先されます。Vault 外の絶対パスへも出力できます。

## 記法

初期状態では、**タグを残す**だけがオフで、それ以外はすべてオンです。

| 設定 | オンにしたときの動作 |
|---|---|
| **ノートの埋め込みを展開する** | `![[ノート]]` と見出し埋め込みを本文へ展開 |
| **dataview / mermaid を描画する** | `dataview`、`mermaid`、`tasks`、`chart` のコードブロックを Obsidian の描画結果へ差し替え |
| **dataviewjs / templater を実行する** | 動的描画中にノート内 JavaScript の実行を許可。信頼できるノートだけでオンにする |
| **《《テキスト》》 を傍点にする** | カクヨム式傍点を変換 |
| **｜漢字《かんじ》 をルビにする** | 青空文庫系のルビを変換。省略形 `漢字《かんじ》` も対象 |
| **^^10^^ を縦中横にする** | 明示的な縦中横を変換 |
| **1〜2 桁数字の自動正立** | 縦組み内の独立した短い半角数字を正立 |
| **==ハイライト== を変換する** | `==...==` を下記の選択に従って変換 |
| **画像の埋め込みを解決する** | `![[画像.png]]` を画像として配置し、出力へ同梱 |
| **ウィキリンクを解決する** | 本の中のノートへリンク。本の外なら文字だけを残す |
| **callout を残す** | コールアウトを印刷可能な囲みとして残す |
| **チェックボックスを残す** | タスクリストを ☐ / ☑ として残す |
| **タグを残す** | `#tag` を本文へ残す。初期値はオフ |
| **［＃改ページ］で強制改ページ** | 青空文庫式の改ページ注記をページ区切りへ変換 |
| **原稿の連続する空行を紙面の空きにする（3 行で 1 行アキ）** | 3 行以上の空行を `n - 2` 行分の空きへ変換 |
| **%%コメント%% を削除する** | Obsidian コメントを出力から除外 |
| **ブロック ID を削除する** | `^block-id` を出力から除外 |

### `==ハイライト==` の扱い

**==ハイライト== を変換する**がオンのときだけ有効です。

| 値 | 出力 |
|---|---|
| `boten` | 傍点 |
| `strong` | 太字の `<strong>` |
| `mark` | `<mark>` の地色 |
| `off` | 記号を外した素の文字 |

変換スイッチ自体をオフにすると、`==` 記号が原稿どおり残ります。

## 造本

### 前付け・後付け

| 部位 | 初期値 | 設定タブでの扱い |
|---|---:|---|
| 半扉 | オフ | 自動生成のオン / オフ |
| 扉 | オン | 自動生成のオン / オフ |
| 献辞 | オフ | `vivlio.yaml` でノートを指定 |
| 題辞 | オフ | `vivlio.yaml` でノートを指定 |
| 目次 | オン | 自動生成のオン / オフ |
| まえがき | オフ | `vivlio.yaml` でノートを指定 |
| あとがき | オフ | `vivlio.yaml` でノートを指定 |
| 付録 | オフ | `vivlio.yaml` でノートを指定 |
| 参考文献 | オフ | `vivlio.yaml` でノートを指定 |
| 謝辞 | オフ | `vivlio.yaml` でノートを指定 |
| 奥付 | オン | 自動生成のオン / オフ |

半扉、扉、目次、奥付は Vivlio が内容を生成できます。それ以外は本文になる Markdown ノートを `sections:` で指定します。

### ノンブル

| 値 | 動作 |
|---|---|
| `roman-then-arabic` | 前付けを `i, ii, iii...`、本文第一章から `1` に戻す。初期値 |
| `continuous` | 最初から最後まで算用数字を通す |
| `none` | ノンブルを出さない |

**目次に拾う見出しの深さ**は 1〜6、初期値は 2 です。

## プレビュー

| 設定 | 初期値 | 解説 |
|---|---:|---|
| **プレビューを自動更新する** | オン | 原稿変更後に再組版。 |
| **更新のデバウンス（ミリ秒）** | `600` | 最後の変更から再組版まで待つ時間。大きくすると連続入力中の再組版を減らせます。 |
| **全ページを最初に描画する** | オフ | 初期表示は遅くなりますが、目次のページ番号を最初から確定します。 |

長い本で入力が重く感じる場合は、自動更新をオフにするかデバウンスを長くしてください。

## PDF

| 設定 | 初期値 | 解説 |
|---|---:|---|
| **タグ付き PDF** | オン | 文書構造タグを生成。アクセシビリティや再利用に役立ちます。 |
| **PDF に栞を付ける** | オン | 目次の階層を PDF アウトラインへ入れます。 |
| **PDF にメタデータを埋め込む** | オン | 書名、著者などを埋め込みます。 |
| **表紙を PDF に含める** | オン | 書き出しダイアログで今回だけ変更も可能。 |
| **書き出し時に外部画像をダウンロードする** | オン | HTTP(S) 画像を出力へ取り込みます。 |
| **Vault 外のファイルを許可する** | オフ | 絶対パスの画像・フォント等を許可。必要な本だけで慎重に使用します。 |
| **実効 dpi の警告閾値** | `300` | 紙面上の解像度が下回る画像を警告。`0` で無効。 |
| **PDF 生成のタイムアウト（ミリ秒）** | `120000` | 組版完了を待つ上限。長大な本では増やします。 |

## 詳細

| 設定 | 初期値 | 解説 |
|---|---:|---|
| **固定ポート** | `0` | プレビュー用ローカルサーバのポート。0 は OS が空きを自動選択。ファイアウォール上の理由がある場合だけ固定します。 |
| **ログレベル** | `error` | `silent`、`error`、`info`、`debug`。調査時だけ詳細化するとログを読みやすく保てます。 |

サーバは `127.0.0.1` にだけ公開され、プレビューまたは書き出しが必要な間だけ起動します。

## 設定を本へ移す・本から取り込む

- **Vivlio: 現在の設定を vivlio.yaml に書き出す** — 設定タブの変更点を現在の本へ書き出します。
- **Vivlio: この vivlio.yaml を Vault の既定にする** — `vivlio.yaml` のテーマ、判型、組方向、脚注、フォント、ノンブルなど一部を設定タブへ取り込みます。
- **Vivlio: 設定リファレンスを書き出す** — すべての本設定キーを既定値とコメント付きで列挙した `vivlio-reference.yaml` を作ります。

共有する本は `vivlio.yaml` に必要な値を置くと、別の Vault や PC でも意図を再現しやすくなります。
