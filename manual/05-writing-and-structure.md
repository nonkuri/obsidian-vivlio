# 原稿の書き方と本の組み立て方

[前: 本ごとの設定](04-book-configuration.md) / [マニュアル目次](00_vivlio_plugin_manual.md) / [次: 自作テーマ](06-custom-theme.md)

## 本にする対象を選ぶ

### 1 ノートを一冊にする

ノートを開き、リボンの本アイコンまたは **Vivlio: プレビューを開く**を実行します。PDF / EPUB コマンドもアクティブノート一つを対象にします。

複数ノートで作成する場合 `title` は章タイトルになり、単独ノートで作成する場合は書名として使われます。別の書名にしたいときは `vivlio-title` を指定します。

### フォルダを一冊にする

ファイルエクスプローラでフォルダを右クリックし、**Vivlio: 本としてプレビュー**または **Vivlio: 本として書き出す**を選びます。

フォルダ**直下**の `.md` だけが章になります。サブフォルダ内のノートは自動収集しません。画像や CSS はサブフォルダに置いて構いません。

### 目次ノートから一冊にする

章への `[[リンク]]` を並べたノートを開き、**Vivlio: このノートを目次として本を組む**を実行します。

```markdown
# 目次

- [[01-序章]]
- [[02-第一部]]
- [[03-終章]]
```

## 章の順序

フォルダ本では次の規則で決まります。

1. 目次ノートがあれば、その本文に現れる `[[リンク]]` の順。
2. 目次に書かれていない同フォルダ直下のノートは、消えずに末尾へファイル名の自然順で追加。
3. 目次ノートがなければ、すべてをファイル名の自然順。`2.md` は `10.md` より前。
4. `vivlio-order` があるノートは、上記より優先して完成後の位置へ挿入。

目次ノートとして自動認識されるのは次のいずれかです。

- `index.md`
- フォルダ名と同名のノート
- フロントマターに `vivlio-toc: true` があるノート

通常、章順を決める目次ノート自身は本文に入りません。含める場合は `vivlio.yaml` に `includeToc: true` を指定します。

## 章タイトルと見出し

章タイトルは次の順で決まります。

1. ノートの通常フロントマター `title`
2. 最初の `# 見出し`
3. ファイル名

自動目次と PDF のしおり、EPUB ナビゲーションには、`tocDepth` までの見出しが使われます。たとえば `tocDepth: 2` なら `#` と `##` までです。

同じ見出し名が複数あっても、VFM と同じ規則で一意なリンク ID が作られます。

## 日本語向け記法

### ルビ

```markdown
漢字《かんじ》
｜任意の文字列《にんいのもじれつ》
{漢字|かんじ}
```

- `漢字《かんじ》` は直前の漢字の連なりを親文字にする省略形です。
- `｜...《...》` は `｜` からルビ直前までを親文字にします。半角の `|` も使えますが、Markdown 表内では `\|` とエスケープしてください。
- `{漢字|かんじ}` は VFM 本来のルビ記法です。

### 傍点

```markdown
その言葉は《《まだ》》届かない。
```

`《《...》》` は傍点になります。`==...==` も初期設定では傍点ですが、設定で太字、`<mark>`、素の文字に変更できます。

### 縦中横

```markdown
午後^^10^^時
^^1/2^^
```

`^^...^^` は最大 4 文字を縦中横にします。また縦組みでは、周囲から独立した 1〜2 桁の半角数字を自動で正立します。数字・英字・ `. , : % -` が前後に接している場合は自動対象になりません。

### 強制改ページ

```markdown
［＃改ページ］

次のページから始めたい段落。
```

注記の次にあるブロックへ `break-before: page` が適用されます。

### 連続空行

3 行以上の連続空行は紙面上の空きになります。原稿で `n` 行空けると、`n - 2` 行分の空きです。この機能が不要なら **原稿の連続する空行を紙面の空きにする**をオフにします。

## 段落の字下げ

小説原稿の行頭全角スペースは「この段落を字下げする」という手掛かりとして読み取られ、初期設定では文字そのものを削除して CSS の `text-indent` に置き換えます。

```markdown
　これは字下げされた地の文です。

「会話文は、括弧が自分の空きを持ちます」
```

この方式により、PDF と EPUB で字下げが安定します。既存原稿の書き方に合わせ、`paragraphIndentMode` を `auto`、`manuscript`、`brackets`、`all` から選べます。

## 脚注

通常の Markdown 脚注を使います。

```markdown
本文中の注です。[^note]

[^note]: ここが脚注本文です。
```

`footnote` の設定により、ページ下部、章末、DPUB-ARIA 形式へ変換されます。縦組みでは `novel` テーマが脚注番号を正立させます。

## Obsidian の記法

### ノートの埋め込み

```markdown
![[資料ノート]]
![[資料ノート#必要な節]]
```

参照先の内容をその場所へ組み込みます。埋め込みは深さ 3 までで、循環参照は拒否されます。大きな本を暗黙に増やさないよう、章として並べる `[[リンク]]` と本文へ複製する `![[埋め込み]]` を使い分けてください。

### ウィキリンク

```markdown
[[第二章]]
[[第二章|次の章]]
```

参照先ノートが同じ本に含まれていればリンクになります。本の外なら移動先ページを作れないため、表示テキストだけを残してリンクを外します。

### コールアウト

```markdown
> [!warning] 注意
> ここは再確認してください。
```

印刷可能な囲みとして残り、`.callout` と `.callout-warning` のようなクラスが付きます。種別名は任意なので、自作テーマで種類別に装飾できます。

### タスクリスト

```markdown
- [ ] 未完了
- [x] 完了
```

PDF にはフォーム部品ではなく、☐ / ☑ の文字として出力されます。

### タグ、コメント、ブロック ID

初期設定では次の扱いです。

- `#tag` — 削除
- `%%コメント%%` — 削除
- `^block-id` — 削除

**タグを残す**をオンにすればタグを本文に残せます。コメントとブロック ID の削除も個別にオフにできます。

## 画像

### Obsidian 埋め込み

```markdown
![[images/挿絵.png]]
![[images/挿絵.png|300]]
![[images/挿絵.png|60%]]
![[images/挿絵.png|80mm]]
![[images/挿絵.png|300x200]]
```

単位なしの `300` は `imageWidthUnit` に従い、初期値は `px` です。画像ごとに `%`、`mm`、`px` を書けばそちらが優先されます。画像は縦横比を保ち、分かる場合は本文領域からはみ出さないように調整されます。

### キャプション付き画像

```markdown
![岬の灯台](images/lighthouse.jpg)
```

通常の Markdown 画像は `<figure>` と `<figcaption>` になり、代替テキストがキャプションとして表示されます。

### 解像度

ラスター画像は紙面上の表示幅から実効 dpi を計算します。初期値では 300 dpi 未満を警告します。SVG はベクターなので dpi 警告の対象外です。

## Mermaid、Dataview、Tasks、Chart

次の言語名を持つコードブロックは、対応する Obsidian レンダラが有効なら描画結果に差し替えられます。

- `mermaid`
- `dataview`
- `tasks`
- `chart`

描画結果は `.vivlio-rendered` を持つブロックとして配置されます。対象プラグインが導入・有効化されていない場合は期待どおりになりません。

`dataviewjs` や Templater の JavaScript 実行は別の安全設定です。自分で書いていない原稿では **dataviewjs / templater を実行する**をオフにしてください。

## コードブロック内は変換しない

ルビ、傍点、縦中横、タグ削除などの前処理は文書ツリーに対して行われ、コードブロックとインラインコードの内容には適用されません。記法そのものを本に掲載したいときはコードとして囲んでください。

## 前付け・本文・後付け

本は次の順に組み立てられます。

```text
表紙
半扉
扉
献辞
題辞
目次
まえがき
本文の各章
あとがき
付録
参考文献
謝辞
奥付
```

半扉、扉、目次、奥付は `auto` で自動生成できます。それ以外は `sections:` に Markdown ノートのパスを指定します。表紙は `cover` の画像か `coverPage` のノートで指定します。

部位に指定したノートは、**本文の章としては組まれません。** 本のフォルダに `あとがき.md` を置いて `afterword` に指定しても、後付けに一度出るだけです。
