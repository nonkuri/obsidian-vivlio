# テーマ別の原稿の書き方

[前: 原稿と本の構造](05-writing-and-structure.md) / [マニュアル目次](00_vivlio_plugin_manual.md) / [次: 自作テーマ](06-custom-theme.md)

この章では、同梱テーマを使って原稿を書く方法を説明します。ルビ・脚注・画像などの共通記法は [原稿の書き方と本の組み立て方](05-writing-and-structure.md)、CSS の変更は [自分でテーマを作ってみる](06-custom-theme.md) を参照してください。

## テーマを選ぶ

| テーマ | 主な用途 | 原稿を書くときのポイント |
|---|---|---|
| `novel` | 日本語小説・縦一段組 | 章・節、会話文の字下げ、ルビ・傍点・縦中横 |
| `essay` | 一般書・エッセイ・縦一段組 | 章のみ改ページ。節見出し、引用、箇条書き、キャプション付き図版 |
| `novel-2col` | 日本語小説・縦二段組 | `novel` と同じ記法。字数・行数は一段あたりで指定 |
| `english-novel` | 英語小説・横組み | 章見出し、場面転換、冒頭段落の字下げ、引用 |
| `manual` | 操作ガイド・技術書 | 手順・注意書き、図表番号と参照、長い表 |
| `paper` | 論文・レポート | 見出し・図表の通し採番、節参照、要旨・参考文献・付録 |

以下の YAML は本の `vivlio.yaml` に書きます。既存の本でテーマだけを変更しても、明示済みの判型・組方向・段数は変わりません。これらも併せて指定してください。

## essay：一般書・エッセイ

文章中心の一般書、随筆集、紀行文向けの縦組みテーマです。設定ウィザードの **一般書・エッセイ（四六判 縦組み）**から始められます。

```yaml
theme: essay
lang: ja
writingMode: vertical-rl
size: 四六判
charsPerLine: 44
linesPerPage: 17
columns: 1
footnote: gcpm
tocDepth: 2
sections:
  titlePage: auto
  toc: auto
  colophon: auto
```

一章一ノートの場合は `#` を章、`##` を節、`###` を小見出しにします。章は改ページし、節・小見出しは同じページの本文に続きます。1ノートに本全体を書く場合は、`title` と同じ書名の `#` と章の `##` を使い、節は `###` にします。この構成では `sections.titlePage: auto` を指定します。扉を省く場合は書名の `#` を原稿から省くと、`##` が最上位の章見出しになります。プラグインが章と判定した見出しに改ページを適用するため、見出しの階層を揃えてください。

本文は1字下げを基本とし、引用は前後の余白と字下げで本文から区別します。通常の Markdown の引用・箇条書き・脚注・ルビ・傍点を利用でき、長い引用や補足はページをまたげます。引用内の出典を別に整えたい場合は、HTMLの `<p class="essay-source">出典</p>` を利用できます。

通常の `![説明](画像のパス)` は横組みのキャプション付き図版になります。図番号は自動表示せず、本文の流れの中に配置します。画像の幅と表題を別々に指定する場合は次の形にします。

```html
<figure>
<img src="images/walk.svg" alt="家と川の位置関係|45mm">
<figcaption>家から川へ向かう道の模式図</figcaption>
</figure>
```

キャプションと余白の分も必要なので、図版は版面いっぱいにせず、小さめの幅から調整してください。表の多い実用書や操作説明は `manual`、図表の通し採番・参照が必要な論文は `paper` が適します。EPUBはリフロー型で、PDFと同じ改ページ・紙面配置を保証するものではありません。

独自CSSの土台には `@import url("vivlio:essay");` を使えます。`--vivlio-essay--chapter-size`（章見出し、初期値 `1.5rem`）、`--vivlio-essay--quote-inset`（引用の字下げ、`2em`）、`--vivlio-essay--secondary-ink`（補助文字、`#444`）、`--vivlio-essay--rule-ink`（補足の罫線、`#aaa`）を変更できます。本設定の字数・行数を省略すると、`novel` と同じ40字×16行が基準になります。

[サンプル原稿](../sample/essay/index.md)と[利用・検証方法](../sample/essay-README.md)も参照してください。

### essayのcallout

種類ごとに罫線や余白が変わります。色の違いだけに頼らず、白黒印刷でも区別できる設計です。サンプル専用CSSは不要です。

| 記法の種類 | 用途 | 表示 |
|---|---|---|
| `note` / `info` | 補足・背景・小話 | 細い実線の囲み |
| `tip` / `hint` | 工夫・発見 | 角丸の破線枠と深緑の見出し |
| `warning` / `caution` | 注意・失敗談の教訓 | 前後の二重線を細線でつないだ囲みと茶色の見出し |
| `quote` / `cite` | 印象的な一言 | 前後の細い括り罫、広めの字下げ、小さな見出し |

```markdown
> [!tip] 私調べの攻略法
> 気になることは紙に預ける。紙は新しい靴下を勧めてこない。

> [!warning] 翌朝の自分へ
> 昨夜のやる気を、当てにしないこと。

> [!quote] 本日の決議
> お湯を沸かした。それだけで、昨日の水より前進している。
```

縦組みでは右側が補足の始まり、左側が終わりです。両側に罫線を置き、前後の本文と範囲を区別します。通常の補足・ヒント・注意は上下も閉じた囲み、引用型は前後の括り罫です。長いcalloutはページをまたぎ、各ページで囲みを描き直します。見出しは後続の本文と一緒に配置します。通常の `>` 引用は従来どおりです。上記以外の種類は `note` と同じ細い実線の囲みで表示し、独自の種類名も失われません。タイトルを省略すると種類名が表示されるため、日本語の読み物では例のようにタイトルを付けると自然です。

独自テーマで色を変える場合は `--vivlio-essay--tip-ink`（初期値 `#285b57`）、`--vivlio-essay--warning-ink`（`#754529`）を利用できます。EPUBには種類とテーマCSSを収録しますが、実際の描画は読書アプリにも依存します。

## novel・novel-2col：日本語小説

### 本の設定

縦一段組の例です。

```yaml
theme: novel
size: A6
writingMode: vertical-rl
columns: 1
```

縦二段組では、たとえば次のようにします。

```yaml
theme: novel-2col
size: A5
writingMode: vertical-rl
columns: 2
charsPerLine: 23
linesPerPage: 17
```

二段組の `charsPerLine` と `linesPerPage` は **一段あたり**の指定です。二段用に原稿を分割したり、手作業で改行して段の長さを合わせたりする必要はありません。段の切り替わりは組版に任せます。図は一段に収まる寸法から試してください。

### 章・節と会話文

一章を一つのノートとして書く例です。

```markdown
# 第一章　帰り道

　停車場《ていしゃば》を出ると、雨はもう上がっていた。

「午後^^10^^時には戻るよ」

　そう言って、彼は《《振り返らずに》》歩き出した。

## 一

　橋の向こうに灯が見えた。
```

ルビ・傍点・縦中横が縦組みで表示されます。字下げの初期設定では、行頭全角スペースを手掛かりに地の文を字下げし、上の会話文は字下げしません。詳しい条件は [段落の字下げ](05-writing-and-structure.md#段落の字下げ) を参照してください。

`第一章` や `一` は原稿に書いた文字です。小説の章番号を `paper` のように本文全体で自動採番する機能ではありません。単独ノートを一冊にする場合は、先頭の `#` が書名として使われる点にも注意してください。

### 場面転換と改ページ

場面の間に空きを置くには、[連続空行](05-writing-and-structure.md#連続空行) を使えます。初期設定では原稿の空行3行が紙面の1行分になります。必ず次のページから始めたい場面には次のように書きます。

```markdown
　その夜のことは、誰も話さなかった。

［＃改ページ］

　翌朝、手紙が届いた。
```

`novel-2col` でも改ページは次のページへの指定です。次の段へ送るための記号ではありません。

## english-novel：英語小説

### 本の設定

```yaml
theme: english-novel
size: 6x9
writingMode: horizontal-tb
lang: en
columns: 1
charsPerLine: null
linesPerPage: null
```

### 章冒頭・場面転換・引用

一章を一つのノートにする例です。

```markdown
# Chapter One

The rain had stopped before she reached the station.

She folded the letter and put it in her pocket.

***

By morning, the platform was empty.

> I shall return before winter.

The date was almost illegible.[^letter]

[^letter]: The letter bears no signature.
```

標準のテーマでは見出し・区切り線の直後の段落を字下げせず、通常の本文段落を字下げします。字下げ幅などを本の設定や追加 CSS で指定している場合は、その指定も反映されます。

空行で挟んだ `***` は短い横罫線となり、場面転換を示します。改ページを指定するものではありません。引用は `>` で書き、テーマでは斜体・字下げなしで表示されます。脚注は共通の Markdown 記法です。`Chapter One` の文字や番号は原稿に書きます。

## manual・paper共通：図表番号と参照

この節の例は、`theme: manual` または `theme: paper` を本に指定して使います。以下の出力例は `lang: ja` で、その図・表が本の最初に現れる場合です。図と表は別々に「図1」「表1」から採番され、本文原稿をまたいで続きます。`lang: en` では「Figure 1」「Table 1」となります。

### 番号付きの図を書く

原稿ノートと同じフォルダに `figures` フォルダを作り、`flow.svg` を置いた例です。

```html
<figure class="fig" id="fig-flow">
  <img src="figures/flow.svg" alt="入力、確認、出力の順に進む流れ">
  <figcaption>作業の流れ</figcaption>
</figure>

<a href="#fig-flow" data-ref="fig"></a>に作業の流れを示します。
```

表題は「図1　作業の流れ」、参照文は「図1に作業の流れを示します。」となります。

- `id` は参照先の名前です。同じノート内で重複させず、`fig-flow` のように空白なしの名前を付けます。
- `figcaption` は紙面に表示する表題です。「図1」を手入力すると自動番号と重複します。
- `alt` は画像の内容を説明する代替テキストです。上の HTML 例では表題と別に書けます。
- `data-ref="fig"` のリンクは中身を空にしておくと、出力時に図番号が入ります。

通常の Markdown 画像も VFM によって `figure` と `figcaption` になり、採番の対象になります。表題と代替テキストを分け、参照用 ID を明示したい場合は上の書き方を使ってください。

### 番号付きの表を書く

表の中身は Markdown で書けます。HTML タグと Markdown 表の間には、例のとおり空行を入れてください。

```markdown
<figure class="tbl" id="tbl-settings">
<figcaption>最初に見直す設定</figcaption>

| 設定名 | 指定例 | 用途 |
| :--- | :--- | :--- |
| `size` | A5 | 用紙の大きさ |
| `baseFontSize` | 10pt | 本文の文字サイズ |

</figure>

<a href="#tbl-settings" data-ref="tbl"></a>を参照してください。
```

表題は「表1　最初に見直す設定」、参照文は「表1を参照してください。」となります。`class="tbl"` は表、`data-ref="tbl"` は表番号の参照を表します。図と表で `data-ref` を取り違えないでください。

通常の Markdown 表だけでは、番号付きの表題は自動追加されません。すべて HTML で書く場合は、次のように `table` 自体に `id` と `caption` を付ける方法も使えます。

```html
<table id="tbl-format">
  <caption>出力形式</caption>
  <thead><tr><th>形式</th><th>用途</th></tr></thead>
  <tbody><tr><td>PDF</td><td>印刷</td></tr></tbody>
</table>

<a href="#tbl-format" data-ref="tbl"></a>から出力形式を選びます。
```

### 別ノートから参照する

図表を `01-start.md` に書き、同じフォルダの `02-check.md` から参照する例です。両方のノートを同じ本の本文に含めます。

```html
<a href="01-start.md#fig-flow" data-ref="fig"></a>の順に進めます。

設定の一覧は<a href="01-start.md#tbl-settings" data-ref="tbl"></a>を参照してください。
```

`href` は「原稿ノートへのパス + `#` + 参照先の `id`」です。出力後の HTML ファイル名を書く必要はありません。図表の順番を変更したときは、再ビルドすると番号と参照が更新されます。番号は EPUB にも含まれます。

`data-ref` を付けない通常のリンクは表示名を維持します。たとえば `[設定一覧](01-start.md#tbl-settings)` は「設定一覧」というリンクになります。

### 番号が出ないときの確認

本の `theme`、表題の有無、参照先の `id` と `href`、`data-ref` の種類を確認してください。HTML と Markdown 表の間の空行も必要です。Obsidian の編集画面ではなく、Vivlio の再ビルド後のプレビューで採番を確認します。

専用の通し採番は、本に `theme: manual` または `theme: paper` を指定したときの組み立て処理です。自作 CSS で `@import url("vivlio:manual")` や `@import url("vivlio:paper")` と書くだけでは有効になりません。標準の採番を保ったまま見た目を調整したい場合は、テーマ名を維持して本の `css` に追加 CSS を書きます。

## manual：操作ガイド・技術書

### 本の設定

```yaml
theme: manual
size: A5
writingMode: horizontal-tb
lang: ja
charsPerLine: null
linesPerPage: null
columns: 1
```

`manual` は見出しの罫線、注意・ヒントの枠、明るい背景のコード、キーボード表記を備えた横組みテーマです。本文は既定で字下げしません。文章中心のハンドブックなどでは `paragraphIndent: 1em` で字下げを指定できます。

### 手順・注意書き・キー表記

```markdown
## プレビューを開く

1. 原稿を保存します。
2. コマンドパレットを開きます。
3. **Vivlio: プレビューを開く**を選びます。

確定するには <kbd>Enter</kbd> を押します。

> [!warning] 注意：原稿を保存する
> 保存してから再ビルドしてください。

> [!note] 補足：本ごとの設定
> 判型は `vivlio.yaml` で指定できます。

> [!tip] ヒント：仕上がりを確認する
> 図表番号と改ページも確認してください。
```

手順は番号付きリスト、キーはキーボード風の枠、コールアウトは種類に応じた囲みで表示されます。注意書きは色だけに頼らず、タイトルにも「注意」「補足」などを書いてください。

### 図表と改ページ

図表は前節の記法で書きます。図と表題を一緒に配置し、図を後の章へ浮動配置しません。本文原稿を `paper` のように一つの組版文書へ結合することもありません。

キャプション付きの表は、見出し行を含めて8行以下なら一まとまりで配置します。それより長い表はページをまたぎ、表題と列見出しを繰り返します。表の途中で手作業で分割したり、表題を再入力したりする必要はありません。1行自体が1ページより高い表や巨大な図は、原稿側でも分割・縮小してください。

[マニュアルサンプル](../sample/manual/index.md) には4原稿、模式図2点、設定表と36行のチェックリストがあります。追加 CSS なしで、原稿間参照・長いコード・注意書き・長表の改ページを確認できます。

## paper：論文・レポート

### 本の設定と原稿の分割

```yaml
title: 実験報告
theme: paper
size: A4
writingMode: horizontal-tb
lang: ja
charsPerLine: null
linesPerPage: null
columns: 1
```

新規作成ウィザードの **論文・レポート（A4・横組み）** でも設定できます。`paper` は明朝系の本文、ゴシック系の見出し、下中央のノンブルを持ちます。

Vivlio 0.14.0以降では本文原稿を一つの組版文書にまとめ、ファイル境界では改ページしません。編集用ノートは分割したままです。明示的な改ページ指定は維持されます。章・節・図表は原稿順に採番され、自動目次と番号参照にも反映されます。

### 見出しの番号と節参照

本の書名を上の設定例の「実験報告」とし、本文ノートを次のように書きます。

```markdown
---
title: 方法
---

# 方法

## 実験条件

条件を統一して比較しました。

### 測定手順

同じ手順で測定しました。

<a href="#実験条件" data-ref="sec"></a>節の条件を用います。
```

扉を出す設定では、本の書名と同じ `#` 見出しは本文から取り除かれます。それを除き、本文に残る最上位の見出しが `1`、その下が `1.1` のように採番されます。この例が最初の本文なら「方法」が `1`、「実験条件」が `1.1`、「測定手順」が `1.1.1` となり、参照文は「1.1節の条件を用います。」となります。複数原稿では最上位の見出しの番号が続くため、見出しの深さをそろえてください。

別ノートからは、たとえば `<a href="02-methods.md#実験条件" data-ref="sec"></a>` と書きます。`data-ref="sec"` は節番号を挿入し、「節」という文字は本文側で付けます。見出しに番号を手入力すると重複します。見出し名が重複するとリンク ID が変わるので、参照先を確認してください。

### 要旨・参考文献・付録

番号の扱いは **各原稿ノートのフロントマター**で指定します。本全体の `vivlio.yaml` には書きません。

```markdown
---
title: 補足資料
vivlio-paper-role: appendix
---

# 補足資料

## 追加実験

追加の結果を示します。

### 実験条件

本文と同じ条件を用いました。
```

本の書名が「実験報告」で最初の付録なら、「補足資料」は「付録A」、「追加実験」は「A.1」、「実験条件」は「A.1.1」となります。

| `vivlio-paper-role` | 見出しの扱い |
|---|---|
| `body`（省略時） | 本文の章・節を通し番号にする |
| `abstract` | 要旨の見出しを番号なしにする |
| `references` | 文献の見出しを番号なしにし、URLの脚注への重複出力を止める |
| `appendix` | 付録A、A.1、付録B…と採番する |
| `unnumbered` | 見出しを番号なしにする |

「Vivlioプロパティ」の追加・編集でも「論文内での役割」を選べます。この指定は見出しの採番などを制御するもので、参考文献の引用番号や文献一覧を自動生成するものではありません。参考文献の本文は原稿に書いてください。

### 図表の配置と長い表

図表の表題・ID・参照は、この章の「manual・paper共通：図表番号と参照」の例を使います。`paper` の図は表題と一緒にページ上部へ浮動配置されます。本文には「下の図」ではなく、`data-ref="fig"` による図番号を書いてください。

図の順序と指定寸法・縦横比を保ち、参考文献・付録の開始時にはそれ以前の未配置の図を出し切ります。図の数や大きさによっては図だけのページになる場合があります。ページフロートに対応しない EPUB 読書アプリでは、原稿順の通常配置になります。

表は浮動配置しません。キャプション付きの表は見出し行を含めて12行以下なら一まとまりで配置し、それより長い表は表題と列見出しを繰り返しながらページをまたぎます。1行がページに収まらない場合は、内容を分割してください。

数式と脚注は [共通記法](05-writing-and-structure.md) を使います。[論文サンプル](../sample/paper/index.md) と [設定例](../sample/paper/vivlio.yaml) には本文7ファイル、図5点、表6点、数式・脚注・参考文献、48行の付録表があります。フォルダ全体を Vault にコピーし、同梱の `vivlio.yaml` からプレビューできます。

`academic` は上流の元テーマで、`paper` は Vivlio 向けの調整版です。`theme: academic` や `@import url("vivlio:academic")` では、ここで説明した `paper` 専用の組み立て処理は行いません。投稿先固有の書式は必要に応じて追加 CSS で調整してください。
