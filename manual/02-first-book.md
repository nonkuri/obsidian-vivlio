# まずは一冊作ってみる

[前: 概要](01-overview.md) / [マニュアル目次](00_vivlio_plugin_manual.md) / [次: プラグイン設定](03-settings.md)

ここでは、二つの章からなる縦組みの文庫本を作り、PDF に書き出します。

## 1. Vivlio を有効にする

### Obsidian からインストールする場合

1. **設定 → コミュニティプラグイン**を開く。
2. コミュニティプラグインを利用できる状態にする。
3. **閲覧**で `Vivlio` を検索する。
4. インストールし、**有効化**する。

### 手動でインストールする場合

リリースの `main.js`、`manifest.json`、`styles.css` を次のフォルダへ置き、Obsidian を再読み込みして Vivlio を有効にします。

```text
<Vault>/.obsidian/plugins/vivlio/
```

## 2. 本のフォルダを作る

Vault に次の構成を作ります。ここでは `本/遠雷` が一冊分のフォルダです。

```text
本/
└─ 遠雷/
   ├─ index.md
   ├─ 01-第一章.md
   └─ 02-第二章.md
```

> `index.md` は章順を指定する目次ノートです。単純にファイル名順でよければ省略できます。

## 3. 原稿を書く

`01-第一章.md`:

```markdown
---
title: 第一章　届かない手紙
---

# 第一章　届かない手紙

　遠くで｜遠雷《えんらい》が鳴った。

「手紙は、まだ届かない」

彼女は《《まだ》》という言葉だけを強く発音した。
```

`02-第二章.md`:

```markdown
---
title: 第二章　夜の配達
---

# 第二章　夜の配達

　時計が^^10^^時を打つころ、配達人が門を叩いた。

［＃改ページ］

## 手紙

封筒には、昨日の日付が記されていた。
```

`index.md`:

```markdown
# 目次

- [[01-第一章]]
- [[02-第二章]]
```

目次ノートは、名前が `index.md`、フォルダと同名、または `vivlio-toc: true` を持つノートのいずれかです。リンクは箇条書きでなくても構いません。Vivlio は本文内の `[[リンク]]` の順序を使います。

## 4. `vivlio.yaml` を作る

1. `遠雷` フォルダ内のどれか一つのノートを開く。
2. コマンドパレットを開く。
3. **Vivlio: 本の設定を作成**を実行する。
4. ウィザードを順に設定する。

最初の一冊なら、次の選択で十分です。

| 手順 | 推奨する入力例 |
|---|---|
**すでに `vivlio.yaml` のある本で実行すると、その内容から始まります。** `vivlio.yaml` を開いた状態でも、本のフォルダ内のノートを開いた状態でも同じです。設定をまとめて変えたいときに、最初の入力をやり直さずに済みます（プリセットは **カスタム** になります）。

| プリセット | **文庫（39字×15行）**。ほかに文庫（40字×16行）、B6、四六判、A5 の縦組み一段組と、新書・B6・A5 の縦組み二段組が選べます |
| 書誌情報 | 書名 `遠雷`、著者名、必要なら発行所と発行日 |
| 造本 | `文庫`、`vertical-rl`、39 字 × 15 行、`gcpm` |
| 前付け・後付け | 扉・目次・奥付は「プラグインに作らせる」。まえがき・あとがきは「新しいノートを作る」を選べば、書き出しと同時に空のノートが用意されます |
| 表紙 | 最初は未指定でも可 |
| フォント | 既定のまま |
| 出力 | 既定のまま |

どの項目にも先頭に **既定値を使う** があります。設定タブで決めた値のまま進むという意味で、ほとんどの項目はこれで構いません。

完了すると `本/遠雷/vivlio.yaml` が作られます。全項目が書き出されますが、**行頭が `#` の行は「既定値を使う」を選んだ項目**で、コメントなので効きません。あとから `#` を消せば、その項目をこの本だけの値にできます。

最低限、手で作るなら次でも構いません。

```yaml
title: 遠雷
author: 山田花子
theme: novel
writingMode: vertical-rl
size: 文庫
charsPerLine: 39
linesPerPage: 15

sections:
  titlePage: auto
  toc: auto
  colophon: auto
```

## 5. 本全体をプレビューする

1. ファイルエクスプローラで `遠雷` フォルダを右クリックする。
2. **Vivlio: 本としてプレビュー**を選ぶ。
3. 右側に開く Vivlio プレビューを確認する。

プレビュー上部では次の操作ができます。

- **再ビルド** — 原稿・設定・CSS を読み直して再組版
- **テーマ** — Vault 全体の既定テーマを変更して保存し、再組版
- **PDF / EPUB** — 現在の対象を書き出しダイアログへ渡す

原稿を編集すると、既定では 600 ms 後に自動で再組版します。自動更新をオフにした場合は **再ビルド**を押してください。

> プレビューツールバーのテーマ選択は一時的な試着ではなく、設定タブの **既定テーマ**を変更します。`vivlio.yaml` に `theme` がある本では本側の指定が優先されるため、その本だけを変えるときは `vivlio.yaml` を編集してください。

### 目次の番号が `??` の場合

画面上の全ページがまだ組まれていないためです。次のどちらかで対応します。

- そのまま書き出す。PDF / EPUB では本全体を組むため確定する。
- **設定 → Vivlio → プレビュー → 全ページを最初に描画する**をオンにする。

## 6. PDF に書き出す

1. プレビュー上部の **PDF** を押す。
2. 形式が `PDF` になっていることを確認する。
3. 書き出し先を確認する。既定では `_output/<書名>.pdf`。
4. 表紙を指定している場合は **表紙を含める**を確認する。
5. **書き出す**を押す。

Vivlio は組版後、ファイルを書き込む前に点検結果を表示します。警告がなければそのまま出力し、警告があれば内容を確認して続行またはキャンセルします。

既定では書き出し後に生成ファイルを開きます。

## 7. EPUB も試す

同じダイアログで形式を `EPUB` に変更するか、プレビュー上部の **EPUB** を押します。EPUB はリフロー型なので、文字サイズや改ページはリーダー側で変化します。縦書き方向、目次、書誌情報、テーマ CSS は収録されます。

表紙がない EPUB は本棚サムネイルが空になるため、配布用では表紙を指定してください。

## 8. 表紙を追加する

たとえば `本/遠雷/images/cover.jpg` を置き、`vivlio.yaml` に追加します。

```yaml
cover: 本/遠雷/images/cover.jpg
coverFit: cover
coverInPdf: true
```

`coverFit: cover` は紙面を埋めるように画像を拡大し、はみ出した部分を切り抜きます。画像全体を必ず見せたい場合は `contain` にします。画像と用紙の縦横比が大きく異なると、書き出し前に警告されます。

> `cover` などのアセットパスは Vault 相対で書くのが確実です。

## 9. うまくいかないとき

| 症状 | 確認すること |
|---|---|
| フォルダ本に章が入らない | 対象はフォルダ直下の `.md`。章がサブフォルダに入っていないか |
| 章順が違う | `index.md` のリンク順、ファイル名、`vivlio-order` を確認 |
| `vivlio.yaml` や `.css` が見えない | **.yaml / .css / .epub をファイルエクスプローラーに表示する**をオンにして Obsidian を再起動 |
| ルビや傍点が変換されない | 設定の **記法**で該当項目がオンか確認 |
| PDF 生成が終わらない | **PDF 生成のタイムアウト**を増やす。巨大画像や動的ブロックも確認 |
| 詳細なエラーを見たい | **Vivlio: 診断ログを書き出す**を実行 |

次は [Vivlio プラグインの設定](03-settings.md) で Vault 全体の既定値を調整します。
