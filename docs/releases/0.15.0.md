# Vivlio 0.15.0

マニュアル・操作ガイド向けのテーマを改善しました。手順、注意書き、設定表、コードを読み分けやすくし、複数の原稿にまたがる図表番号と参照を揃えます。

## 変更内容

- 見出しの罫線、番号付き手順、キー表記、注意・ヒント・補足の枠を整備。コードは明るい背景と濃い文字で表示します。
- `theme: manual` の本文にあるキャプション付き図表を通し採番し、`data-ref="fig"` / `data-ref="tbl"` の参照をPDF・EPUBへ反映します。章の順序と見出しは原稿どおりです。
- 長い手順・注意書き・コードはページをまたげます。短い表は一緒に置き、長表は表題・列見出しを繰り返します。図は説明の近くに保ち、キャプションと一緒に配置します。
- 扉・奥付の余白と、長い設定名・URLの折り返しを改善しました。
- 日英README、設定マニュアル、テーマガイド、仕様書、サンプルの説明を更新しました。

## 既存のマニュアルを更新する場合

本文の既定の字下げを `1em` から `0` に変更しました。以前の見た目を保つ場合は、`vivlio.yaml` に `paragraphIndent: 1em` を指定してください。図表番号は自動で付くので、キャプションに手書きしていた番号は取り除いてください。`vivlio:manual` をimportした自作テーマでは、採番ではなくスタイルだけが適用されます。

## English

The manual theme now distinguishes procedures, callouts, settings, code and keyboard keys. Captioned figures and tables receive book-wide numbers, with cross-note references preserved in PDF and EPUB. Long callouts and tables can span pages; table captions and headers repeat on continuation pages.

**Compatibility:** manual paragraphs now default to no first-line indent. Set `paragraphIndent: 1em` to restore the previous indent. Remove hand-written figure/table numbers from captions. Custom themes importing `vivlio:manual` receive styles only, without the numbering pass.

The attached manual sample includes four Japanese source notes, two schematic SVG figures, a 36-row checklist, a 16-page A5 PDF and an EPUB. Install the plugin using the three loose assets `main.js`, `manifest.json` and `styles.css`.
