## 追加

- 句集用 `haiku`、歌集用 `tanka` の内蔵テーマと作成プリセットを追加しました。テーマCSSを別途配置する必要はありません。
- `[!haiku]` / `[!tanka]` で一句・一首の境界を指定し、`versePerPage` で1・2・3作品／ページを選べます。詞書、作者、ルビ、意図した改行を保持します。
- 章題は左ページ始まりの半扉、連作見出しは冒頭の作品と同じページに配置します。EPUBは固定のページ枠を外してリフローします。

## 修正

- 小説・二段組小説・エッセイ・句集・歌集の本扉を見直しました。書名をやや右上、著者名を左下に配置し、ページ端への分離と中央への密集を抑えています。

## ドキュメントとサンプル

- README、マニュアル、テーマ別の原稿記法、設定リファレンスを更新しました。
- [句集・歌集の原稿、6種類のPDF、2種類のEPUB](https://raw.githubusercontent.com/nonkuri/obsidian-vivlio/0.17.0/sample/downloads/vivlio-sample-verse-0.17.0.zip)を公開しました。[使い方](https://github.com/nonkuri/obsidian-vivlio/blob/0.17.0/sample/verse-README.md)。
- サンプルはリポジトリから配布します。このリリースの添付資産はObsidianが使用する `main.js`・`manifest.json`・`styles.css` のみです。

## 検証と制限

- 回帰テスト、型検査、本番ビルドを実施。縦書き5テーマの本扉15例と、表紙・目次・ノンブルの32例をブラウザで確認しました。
- 句集・歌集の1・2・3作品／ページ、章扉の左右、連作見出し、長い作品の全量保持、EPUB構造を検証しました。
- 天地揃えと長文の注釈を中心とする構成は標準対象外です。長い作品の収まりは推定と警告に加え、プレビューでも確認してください。

デスクトップ版Obsidian 1.8.7以降が必要です。
