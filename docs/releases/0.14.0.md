# 0.14.0 — 論文・レポート用paperテーマ

複数のノートから論文を組むための `paper` テーマと「論文・レポート（A4・横組み）」プリセットを追加しました。章・節・図表の番号を原稿に手入力せず、論文全体で自動採番できます。

- 本文原稿を自然につなぎ、章・節・図表の通し番号を目次とID参照にも反映します。
- ノートの `vivlio-paper-role` で要旨・参考文献・付録・番号なし原稿を指定できます。付録はA、A.1形式になります。
- 図をキャプションと一体でページ上部へ浮動配置し、後続の本文で余白を埋めます。参考文献・付録へ図が持ち越されるのを防ぎます。
- 長表では表題・列見出し・「続き」を再掲します。一段組で長表の後の本文が版面外へ流れる問題と、参考文献URLの重複表示も修正しました。
- 日本語・英語のREADME、設定・テーマのマニュアル、仕様書と検証記録を更新しました。

## 論文サンプル

[vivlio-sample-paper-0.14.0.zip](https://github.com/nonkuri/obsidian-vivlio/releases/download/0.14.0/vivlio-sample-paper-0.14.0.zip) に、原稿7ファイル、図5点、表6点、数式・脚注、48行の付録表、合成データと再現コード、実機出力PDFを収録しています。手入力番号や追加CSSは使っていません。

ZIP内の `paper` フォルダをVaultへコピーし、`vivlio.yaml` を右クリックしてプレビューしてください。図は生成済みで、組版にPythonは不要です。

実機PDFは全15ページを確認済みです。図3・図4が同じページに収まり、以前の大きな余白は解消しています。図表の順序、目次、長表の全48行、最終段落の表示を確認しました。フォント・環境によって改ページ位置は変わります。

## 検証

通常テスト、型チェック、配布用ビルドに加え、同梱Vivliostyle・Chromeで3種類のノンブル設定を検証しました。EPUBへの図・数式・付録の収録も自動検査しています。EPUB読書アプリでの表示確認は未実施です。
