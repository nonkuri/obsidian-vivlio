## エディタとプレビューの双方向連動

- エディタでカーソルを動かすと、該当段落の先頭があるページへプレビューが追従します。段落内の移動だけでは再ビルドしません。
- プレビューの文章をクリックすると、元ノートの段落先頭へカーソルとスクロール位置を移動します。開いている原稿は既存タブを使い、開いていない原稿は画面を分割せず新規タブで開きます。
- 見出し・箇条書き・コードブロック、ノートの埋め込み、論文形式で結合した原稿にも対応します。原稿が閲覧モードなら編集モードへ切り替えます。
- ツールバーの「カーソル連動：オン／オフ」に現在の状態を表示します。ペインを開いたときはオンで、押すとそのペインの両方向の連動を切り替えられます。
- リンクのクリック、文字の範囲選択、修飾キー付きのクリックは通常どおり使えます。
- 埋め込みの構文がMarkdownパーサーによって複数ノードに分かれる場合も、ノート全体・見出し指定の埋め込みを展開できるよう修正しました。

## 対応範囲と使い方

- 連動は段落単位です。複数ページにまたがる段落への追従先は先頭ページであり、クリックした文字そのものへは移動しません。
- 再ビルド中や、編集した原稿がプレビューへ未反映の間は位置移動を待ちます。自動更新が無効の場合は「再ビルド」を押してください。
- 自動生成された目次など、対応する原稿の段落がない部分は移動対象外です。同期用の対応情報はPDF・EPUBへ出力しません。
- README（日英）、マニュアル、仕様書に操作方法・新規タブの動作・制限を追記しました。

## 検証

- 型検査、自動テスト一式、本番ビルドを実施。原稿が未反映の場合、再ビルド中、既存タブの再利用、新規タブでの表示、閲覧モードからの切り替え、連動オフを回帰テストで確認しました。
- Chromeと同梱Vivliostyleを使い、縦書きと論文形式で、行番号・埋め込み元・見出し／箇条書き／コード、遅延組版中のページ移動とクリックの対応を検証しました。
- Obsidian本体での自動操作検証は行っていません。リポジトリ全体のlintには既存エラーが残っています。
- リリース資産は `main.js`・`manifest.json`・`styles.css` の3点です。対応するObsidianの最低バージョンは1.8.7のままです。
